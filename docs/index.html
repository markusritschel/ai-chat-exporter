Set up once, use on every chat

No extension and no account — the whole tool lives in one bookmark.

  1. Add it to your bar

    Pull the Chat Export button up into your bookmarks bar.

  2. Open a conversation

    On claude.ai, chatgpt.com or chat.mistral.ai.

  3. Click to save

    A small notice confirms the export, and the Markdown file lands in your downloads.

Bookmarks bar hidden, or dragging not working?

Copy the code, create a bookmark by hand and paste the code in as its address. It behaves exactly like the dragged one.

Everything, exactly as written

It reads each app's own data — never the rendered page — so nothing is lost in translation.

Source-level fidelity

Tables, formulas and code blocks come from the assistant's own markdown — nothing is scraped from the screen or converted from HTML.

The version you see

Regenerated or edited a message? The export follows the branch that's on your screen.

Made for notes and retrieval

Frontmatter turns into Obsidian properties, and one heading per turn gives retrieval pipelines tidy chunks.

Artifacts & attachments

Claude's artifacts, created files and charts as fenced code; uploads noted above the message.

Long chats, complete

Stays on your machine

Your data stays with you

For your conversation, the bookmark talks only to the chat app you're signed in to. It asks for the conversation the same way the app itself does, turns it into Markdown inside your tab and hands the file to your browser. No copy goes anywhere else.

Each run also compares your bookmark with the newest version on GitHub; if yours is outdated, a notice says so — drag the button again to refresh it. That check downloads a public file and sends nothing about you or your chats.
